AllSense Control

v1.0.0 · dikembangkan oleh Maxodus

Panel kontrol ringkas untuk kecerahan, volume, dan mode daya Windows — universal, tanpa admin, tanpa driver vendor.

Unduh setup.exe Lihat Source

Mode Daya

Hemat / Balanced / Turbo — pindah cepat lewat klik atau hotkey, dengan OSD animasi ala laptop gaming.

Kecerahan & Volume

Slider menyinkronkan kondisi asli perangkat dan ikut perubahan tombol Fn / OS.

Status Wi-Fi & Bluetooth

Indikator hidup/mati radio secara langsung dari Windows.

Hotkey Kustom

Ketik atau rekam kombinasi Anda sendiri; tersimpan permanen.

Shortcut bawaan

Tampilkan / sembunyikan window — Ctrl+Alt+A
Ganti mode daya — Ctrl+Alt+M (ubah sesuai keinginan)

Persyaratan

Windows 10/11 · 64-bit · .NET 10 self-contained (tanpa runtime bawaan).
